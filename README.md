# ShareSpend Pro — Smart Expense Splitter

A modern, high-performance, mobile-first Web Application designed for multi-currency group expense splitting, featuring a multi-lingual AI Voice Assistant, Trip-wise Debt Isolation, and Data-Driven Quizzes.

## 🔗 Links
- **Live Application:** [https://khandekarakshayr.github.io/sharespend-pro/](https://khandekarakshayr.github.io/sharespend-pro/)

## ✨ Key Features
- **Context-Aware Voice Control:** Multi-lingual support (Marathi & English) with script-tolerant intent matching.
- **Strict Trip-Wise Debt Isolation:** Granular debt tracking per event/trip.
- **Multi-Mode Payment Tracking:** Categorize expenses by UPI, Cash, Card, or Bank.
- **Media Vault:** Canvas-compressed image uploads with removal controls.
- **Dynamic Quiz Generator:** Auto-generated interactive quizzes based on active trip data.

## 🛠️ Tech Stack
- Vanilla JavaScript (ES6+ Architecture)
- HTML5 & Custom CSS Design System
- Web Speech API & LocalStorage State Management
